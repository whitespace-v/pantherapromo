# Автотехцентр «Пантера» — сайт на Next.js

Полноценное приложение на **Next.js 14 (App Router) + TypeScript**. Собрано из повторяющегося HTML
старого сайта: общий шаблон вынесен в компоненты, а всё, что меняется от услуги к услуге, лежит
в данных (`app/lib/services-data.ts`). Одна страница-шаблон рендерит все 29 услуг.

## Быстрый старт

```bash
npm install
npm run dev      # http://localhost:3000
```

Сборка и продакшн:

```bash
npm run build
npm start
```

> **Важно:** перед запуском положите изображения старого сайта в `public/images/`
> (файлы `4.jpg`, `6.jpg`, `8.JPG`, `11.JPG`, `3.JPG`, `13.JPG`, `5.JPG`, `16.JPG`,
> папки `avatars/` и `reviews/`). Пути в коде уже указывают на `/images/...`.

## Что где лежит

```
app/
  layout.tsx                 # <html>, шрифт Inter (next/font), шапка/подвал, JSON-LD организации
  page.tsx                   # главная — собрана из секций
  globals.css                # вся ваша дизайн-система (перенесена из styles.css)
  sitemap.ts                 # автоматический sitemap: главная + все услуги
  robots.ts                  # robots.txt
  not-found.tsx              # страница 404
  favicon.ico
  lib/
    site.ts                  # ЕДИНЫЙ источник данных: телефон, адрес, гео, соцсети, реквизиты
    services.ts              # модель услуги + помощники
    services-data.ts         # КОНТЕНТ всех 29 услуг
  components/
    Header.tsx  Footer.tsx  Logo.tsx
    Reveal.tsx               # плавное появление при скролле (замена reveal-обсервера)
    LeadForm.tsx             # форма заявки (отправляет в WhatsApp сервиса)
    Contacts.tsx  MapWidget.tsx  JsonLd.tsx
    home/                    # секции главной: Hero, Services, Gallery, About, Reviews, Corporate
  uslugi/
    [slug]/page.tsx          # ШАБЛОН страницы услуги (SSG + метаданные + JSON-LD)
```

## Как добавить / изменить услугу

Всё в `app/lib/services-data.ts`. Добавили объект в массив — и услуга сразу:
появляется в каталоге на главной, получает свою страницу `/uslugi/<slug>`,
попадает в `sitemap.xml` и получает микроразметку. Ничего больше править не нужно.

## Контакты и реквизиты

Меняются в одном месте — `app/lib/site.ts`. Обновляются на всём сайте и во всей SEO-разметке.

## SEO

- Уникальные `<title>` и `description` на каждой странице (Metadata API).
- Canonical, Open Graph, Twitter Card.
- JSON-LD: `AutoRepair/LocalBusiness` (везде), `Service` + `Offer`, `BreadcrumbList`,
  `FAQPage` (на страницах услуг), `ItemList` каталога (на главной).
- Автоматический `sitemap.xml` со всеми страницами и `robots.txt`.
- 301-редиректы со старых `/*.html` на новые `/uslugi/*` (в `next.config.mjs`) — на случай,
  если старый статический сайт уже был проиндексирован.

## Живая карта (по желанию)

Сейчас блок карты — надёжная статическая карточка с кнопками «2ГИС» и «Яндекс Карты».
Чтобы встроить живую карту, замените содержимое `.map-placeholder` в `app/components/MapWidget.tsx`
на официальный iframe/виджет 2ГИС или конструктор Яндекс.Карт (id организации в 2ГИС:
`70000001104631252`, координаты — в `app/lib/site.ts`).

## Замечания по решениям

- Из стартера (Tailwind v4 + framer-motion) я **убрал эти зависимости** и оставил вашу
  дизайн-систему как обычный CSS — так меньше движущихся частей и надёжнее сборка.
  Анимации появления сделаны лёгким компонентом `Reveal` (IntersectionObserver).
- Форма без бэкенда: по сабмиту открывает WhatsApp сервиса с уже заполненным текстом.
  Когда появится сервер/сервис форм — поменяйте `onSubmit` в `LeadForm.tsx`.

Список найденных проблем контента старого сайта — в `ЗАМЕЧАНИЯ-ПО-КОНТЕНТУ.md`.
